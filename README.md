### Zepto SQL Analysis

Project Overview

This project contains SQL queries and analysis performed on the Zepto sales dataset.

Tools Used

- MySQL
- SQL
- GitHub

Dataset

The dataset contains Zepto product and sales-related information, including:

- Product Name
- Category
- City
- Original Price
- Current Price
- Discounts
- Orders
- Total Revenue
- Influencer Active

SQL Topics Covered

- Basic SQL Queries
- Filtering and Sorting
- Aggregate Functions
- GROUP BY and HAVING
- DISTINCT
- Joins
- Subqueries
- Window Functions
- Ranking
- Advanced SQL Queries

Project Files

- "zepto_queries.sql" — SQL queries used for the analysis

Objective

The objective of this project is to practice SQL and extract meaningful insights from the Zepto sales dataset.

### Level 3 - Advanced SQL
1. Rank products by total revenue within each category.

<details>
<summary>Show Answer</summary>

```sql
SELECT
    Category,
    `Product Name`,
    `Total Revenue`,
    RANK() OVER (
        PARTITION BY Category
        ORDER BY `Total Revenue` DESC
    ) AS revenue_rank
FROM zepto_sales_dataset;
```
</details>

2. Find the top 3 products by total revenue within each category using DENSE_RANK().

<details>
<summary>Show Answer</summary>

```sql
SELECT Category, `Product Name`, `Total Revenue`
FROM (
    SELECT
        Category,
        `Product Name`,
        `Total Revenue`,
        DENSE_RANK() OVER (
            PARTITION BY Category
            ORDER BY `Total Revenue` DESC
        ) AS revenue_rank
    FROM zepto_sales_dataset
) AS ranked_products
WHERE revenue_rank <= 3;
```
</details>

3. Assign a unique row number to products based on their total revenue within each category.

<details>
<summary>Show Answer</summary>

```sql
SELECT
    Category,

    `Total Revenue`,
    ROW_NUMBER() OVER (
        PARTITION BY Category
        ORDER BY `Total Revenue` DESC
    ) AS revenue_row_number
FROM zepto_sales_dataset;
```
</details>

### Level - 4 SQL Mastery
1. Using a CTE, find the total revenue generated by each product category and display only categories with total revenue greater than 100,000.

<details>
<summary>Show Answer</summary>

```sql
WITH category_revenue AS (
    SELECT
        Category,
        SUM(`Total Revenue`) AS total_revenue
    FROM zepto_sales_dataset
    GROUP BY Category
)
SELECT Category, total_revenue
FROM category_revenue
WHERE total_revenue > 100000;
```
</details>

2. Using a CTE, find the top 3 products with the highest total revenue.

<details>
<summary>Show Answer</summary>

```sql
WITH ranked_products AS (
    SELECT
        `Product Name`,
        `Total Revenue`,
        DENSE_RANK() OVER (
            ORDER BY `Total Revenue` DESC
        ) AS revenue_rank
    FROM zepto_sales_dataset
)
SELECT `Product Name`, `Total Revenue`
FROM ranked_products
WHERE revenue_rank <= 3;
```
</details>

5. Find the month-wise total revenue using the date column in the dataset.

<details>
<summary>Show Answer</summary>

```sql

    YEAR(`Date`) AS revenue_year,
    MONTH(`Date`) AS revenue_month,
    SUM(`Total Revenue`) AS total_revenue
FROM zepto_sales_dataset

ORDER BY revenue_year, revenue_month;
```
